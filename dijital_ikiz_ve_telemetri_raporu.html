BÖLÜM 5: WEB TABANLI DİJİTAL İKİZ VE TELEMETRİ MİMARİSİ

5.1. Giriş ve Mimari Motivasyon

Mekatronik ve kontrol mühendisliği projelerinde çok değişkenli (MIMO), dinamik olarak kararsız sistemlerin parametre optimizasyonu (PID/LQR tuning) ve çalışma anındaki davranışlarının izlenmesi büyük önem taşır. Klasik laboratuvar ortamlarında kullanılan masaüstü arayüz yazılımları (LabVIEW, Python PyQt, MATLAB GUI veya C# Windows Forms);

  • Kullanıcı tarafında harici çalışma zamanı (runtime) ortamı ve kütüphane kurulumları gerektirmesi,
  • İşletim sistemine özel USB-UART dönüştürücü sürücü bağımlılıkları (FTDI, CH340, CP2102 vb.),
  • Donanım grafik hızlandırmasından (GPU) tam olarak yararlanamayıp yüksek CPU kullanımına yol açması

nedenleriyle dağıtım ve kullanım açısından kısıtlayıcıdır.

Bu bitirme projesi kapsamında, klasik masaüstü uygulamalarının kısıtlarını aşmak ve modern Endüstri 4.0 / SCADA vizyonuna uygun bir altyapı kurmak amacıyla Web Tabanlı Sıfır Kurulumlu (Zero-Install) Sayısal İkiz ve Telemetri Platformu geliştirilmiştir. Geliştirilen platform şu temel hedefleri karşılar:

  • Sürücüsüz ve Eklentisiz Donanım Erişimi: Doğrudan Google Chrome / Microsoft Edge tarayıcıları üzerinden Web Serial API kullanılarak mikrodenetleyici COM portuna çift yönlü ve düşük gecikmeli bağlantı sağlanması.
  • 60 FPS Donanım Hızlandırmalı 3D Kinematik Simülatör: WebGL ve Three.js altyapısıyla 6-DOF Stewart platformunun (taban, servo gövdeleri, kollar, karbon itici çubuklar ve rezistif dokunmatik plaka) fotogerçekçi ve fiziksel ölçülerle 1:1 ölçekli mekatronik canlandırması.
  • Ayrık Zamanlı Fizik ve Kontrol Simülasyonu (SIL): Donanım bağlı değilken dahi sistemin kararlılığını test edebilmek amacıyla, tarayıcı render frekansından bağımsız koşan, alt adımlı (sub-stepping, Δt ≤ 2 ms) ve Arduino ayrık PID kodunu birebir işleten bir sayısal fizik motoru.
  • Yüksek Frekanslı Gerçek Zamanlı Telemetri: Chart.js motoru ile 20-30 Hz bandında kayan pencereli (sliding window) grafik akışı ile top konumları (X, Y), hatalar, kestirilen hızlar (Vx, Vy) ve plaka eğim açılarının (Roll, Pitch) anlık analizi.
Sayısal İkiz (Digital Twin) Kavramının Projedeki Yeri:
Sistem sadece pasif bir grafik izleme arayüzü değildir. Arduino/ESP32 mikrodenetleyicisinde çalışan ters kinematik, ADC sinyal filtreleme (EMA) ve PID kontrol algoritmalarını hem donanımdan gelen anlık UART akışıyla (Hardware-in-the-Loop) hem de matematiksel fizik motoruyla (Software-in-the-Loop) yürüten çift modlu dinamik bir ikizdir.

5.2. Web Serial API Tabanlı Telemetri İletişim Hattı

Mikrodenetleyici (Arduino/ESP32) ile tarayıcı arasındaki veri akışı, W3C standartlarında tanımlanan Web Serial API kullanılarak inşa edilmiştir. Bu mimaride WebSocket sunucusu, yerel Node.js arka yüzü veya Python köprüsüne ihtiyaç duyulmaz.

5.2.1. Seri İletişim Hattı ve Akış Okuma (Streaming Pipeline)

Kullanıcı arayüzdeki "Seri Porta Bağlan" butonuna bastığında tarayıcı işletim sisteminin güvenli aygıt seçim penceresini tetikler. Bağlantı 115200 baud hızında açıldıktan sonra gelen bayt akışı (binary stream) TextDecoderStream üzerinden UTF-8 metne dönüştürülür ve satır satır tamponlanarak asenkron bir döngüde tüketilir:

// Web Serial API Bağlantı ve Asenkron Akış Yönetimi (app.js) async connectSerial() { try { this.port = await navigator.serial.requestPort(); await this.port.open({ baudRate: 115200 }); const textDecoder = new TextDecoderStream(); this.readableStreamClosed = this.port.readable.pipeTo(textDecoder.writable); this.reader = textDecoder.readable.getReader(); while (true) { const { value, done } = await this.reader.read(); if (done) break; if (value) { this.serialBuffer += value; const lines = this.serialBuffer.split('\n'); this.serialBuffer = lines.pop(); // Tamamlanmamış son satırı tamponda tut for (const line of lines) { this.processSerialLine(line.trim()); } } } } catch (err) { console.error("Seri Port İletişim Hatası:", err); } }

5.2.2. Telemetri Veri Paketi Ayrıştırma (Regex Parsing)

Mikrodenetleyici döngüsünden her çevrimde üretilen telemetri paketi düzenli ifadelerle (Regular Expressions) yüksek hızda taranır. Gömülü yazılımdaki seri port formatı:

X: 15.42 mm | Y: -8.10 mm | Aci X: 1.25 deg | Aci Y: -0.68 deg

Ayrıştırılan değerler anında UI durum kartlarına, Chart.js telemetri grafik tamponlarına ve Three.js 3D plaka oryantasyon fonksiyonuna iletilir:

Telemetri Parametresi Birim Fiziksel Anlamı 3D Model ve Grafikteki Karşılığı
X Konumu (x_m) mm Topun rezistif panel uzun kenarındaki konumu 3D Plaka üzerinde küre X ekseni ötelemesi
Y Konumu (y_m) mm Topun rezistif panel kısa kenarındaki konumu 3D Plaka üzerinde küre Y ekseni ötelemesi
Roll Açısı (φ) Derece (deg) Stewart platformunun X ekseni etrafındaki eğimi Üst plakanın Three.js Z-Y-X Euler dönüşümü
Pitch Açısı (θ) Derece (deg) Stewart platformunun Y ekseni etrafındaki eğimi Üst plakanın Three.js Z-Y-X Euler dönüşümü
Hızlar (Vx, Vy) mm/s Sayısal türev ile elde edilen anlık hız vektörü Hız telemetri grafiği ve kinetik enerji takibi

5.3. Üç Boyutlu Kinematik ve Mekatronik Sayısal İkiz Modellemesi (Three.js)

Platformun 3D görselleştirmesi, tarayıcının WebGL grafik işlemcisini doğrudan kullanan Three.js kütüphanesi üzerine kurulmuştur. Mekatronik yapıyı tam olarak yansıtmak amacıyla her bir bileşen gerçek fiziksel ölçüleri ve PBR (Physically Based Rendering) malzeme özellikleriyle modellenmiştir.

5.3.1. Mekatronik Bileşenler ve Geometrik Hiyerarşi

  1. CNC Alüminyum Taban Plakası: Altıgen biçimli, 6 adet kauçuk/alüminyum yükseltme ayağına sahip ve çift katmanlı pahlı işleme havuzlu taban (R_taban = 12.0 cm).
  2. MG996R Servo Motor Gövdeleri ve CNC Braketler: Motor gövdeleri altıgen taban plakasının çevre kenarlarına paralel (teğetsel) doğrultuda yerleştirilmiştir. Taban sacına krom cıvatalarla sabitlenen CNC L-braketler içinde durmakta; mavi eloksallı alüminyum soğutucu gövde bandı, soğutma kanatçıkları ve rulman kulesi içermektedir.
  3. CNC Eloksallı Servo Kolları (Horns): Motor çıkış miline bağlanan kollar teğetsel dönüş ekseni etrafında dönerek radyal olarak dışarıya (R ≈ 16 cm) doğru uzanır. Kollar üzerinde ağırlık hafifletme delikleri ve uç kısımlarında krom küresel mafsal pimi yer alır.
  4. Karbon Fiber İtici Çubuklar (Pushrods / Legs): Servo kollarının ucundaki küresel mafsaldan (sx, sy, sz), üst plakanın altındaki çatal mafsallara (Px, Py, Pz) uzanan karbon fiber boru, alüminyum yüksükler ve Heim tipi mafsal gözlerinden oluşur (L = 15.0 cm).
  5. Hareketli Üst Plaka ve Rezistif Dokunmatik Panel: Dairesel CNC alüminyum çerçeve üzerine monte edilmiş 222 mm × 130 mm ebatlarında dokunmatik ekran, yarı saydam cam materyali ve yüzey koordinat ızgarası.
  6. Krom Rulman Topu: Plaka eğimine göre üzerinde serbestçe yuvarlanan 20 mm çapında parlatılmış çelik küre.

5.3.2. Gerçek Zamanlı Ters Kinematik Kapalı Zincir Çözümü

Gerek seri porttan gelen gerekse simülatörün ürettiği Roll (φ), Pitch (θ) ve yükseklik (h) değerleri her karede updateKinematics() fonksiyonuna beslenir. Burada 6 bacağın servo açıları analitik olarak çözülür:

// Stewart Platformu Ters Kinematik Analitik Çözümü (simulation.js) const alpha_rad = Math.asin(val / r) - Math.atan2(lx_p, lz_p); // 6 Servo kolunun tamamı dışa doğru yönelir ve simetrik olarak yukarı/aşağı kalkar const actualAlpha = alpha_rad; arm.rotation.set(0, 0, baseAngle); arm.rotateY(-actualAlpha); // Servo kol ucunun uzay koordinatları const sx_local = SimConfig.SERVO_KOL_UZUNLUGU * Math.cos(actualAlpha); const sz_local = SimConfig.SERVO_KOL_UZUNLUGU * Math.sin(actualAlpha); const sx = bx + sx_local * Math.cos(baseAngle); const sy = by + sx_local * Math.sin(baseAngle); const sz = 1.0 + sz_local; // Karbon fiber çubuğun iki mafsal arasına yönlendirilmesi ve ölçeklenmesi const startPt = new THREE.Vector3(sx, sy, sz); const endPt = new THREE.Vector3(Px_new, Py_new, Pz_new); leg.position.copy(new THREE.Vector3().addVectors(startPt, endPt).multiplyScalar(0.5)); leg.quaternion.setFromUnitVectors(new THREE.Vector3(0, 1, 0), endPt.clone().sub(startPt).normalize());

5.4. Sayısal Fizik Simülasyon Motoru (Software-in-the-Loop)

Platformun "Simülatör Modu", fiziksel donanıma gerek kalmadan PID parametrelerini doğrulamak için geliştirilmiş deterministik bir yazılım test yatağıdır.

5.4.1. Alt Adımlı (Sub-stepping) Entegrasyon

Web tarayıcılarında ekran yenileme frekansı (60 Hz veya 144 Hz) ve kareler arası dalgalanmalar (Δt) fizik simülasyonlarında kararsızlığa yol açabilir. Bu sorunu önlemek amacıyla simülatör çekirdeğinde alt adımlı sayısal entegrasyon tekniği uygulanmıştır. İki grafik karesi arasındaki zaman farkı maksimum 2 ms'lik dilimlere bölünerek entegre edilir:

// Alt Adımlı Fizik Döngüsü (simulation.js) const MAX_SUBSTEP = 0.002; // Maksimum 2 ms alt adım let remaining = dt; while (remaining > 0) { const step = Math.min(remaining, MAX_SUBSTEP); // Eğim açılarından kaynaklanan yerçekimi ivmesi (kaymadan yuvarlanan dolu küre: 5/7*g*sin(theta)) const ax = SimConfig.YUVARLANMA_KATSAYISI * SimConfig.GRAVITY * Math.sin(thetaX_rad) * 1000.0; const ay = SimConfig.YUVARLANMA_KATSAYISI * SimConfig.GRAVITY * Math.sin(thetaY_rad) * 1000.0; // Euler hız ve konum entegrasyonu sim.vx += (ax - SimConfig.SURTUNME * sim.vx) * step; sim.vy += (ay - SimConfig.SURTUNME * sim.vy) * step; sim.x += sim.vx * step; sim.y += sim.vy * step; remaining -= step; }

5.4.2. Arduino Birebir Filtre ve PID Simetrisi

Simülasyon ortamında topun konumu doğrudan ideal değer olarak okunmaz; Arduino'daki loop() fonksiyonu ile aynı biçimde 33 ms periyotla örneklenir, koordinat dönüşüm matrisinden geçirilir, r = 0.30 parametreli EMA filtresinden geçirilir ve türev sınırlayıcıya ([-500, +500] mm/s) tabi tutulur. Bu sayede donanımda gözlemlenen kısa kenar rezonansı ve faz gecikmesi simülatörde de birebir modellenmiştir.

5.5. Gerçek Zamanlı Çok Kanallı Telemetri Grafikleri (Chart.js)

Sistemin dinamik davranışını izlemek amacıyla üç bağımsız grafik kanalı tasarlanmıştır:

  1. Konum Grafiği: X ve Y eksenlerindeki anlık top konumları (mm) ve merkeze (0, 0) olan yakınsama eğrileri.
  2. Hız Grafiği: Filtrelenmiş veriden türetilen Vx ve Vy hızları (mm/s), aşım ve salınım frekansı tespiti.
  3. Plaka Açıları Grafiği: Kontrolcünün platforma uyguladığı Roll ve Pitch açıları (derece).

Grafik motorunda bellek sızıntısını önlemek amacıyla son 150 örnek kayan pencerede tutulmakta, animasyonlar devre dışı bırakılarak GPU bellek kopyalamaları minimize edilmektedir.

6.3. Yazılım Bileşenlerinin Detaylı Teknik Analizi

1. index.html (Dashboard ve Arayüz Düzeni)

Uygulamanın görsel omurgasını oluşturur. Ekran iki ana sütuna bölünmüştür: Sol sütunda 3D Stewart platformunun gerçek zamanlı canlandırıldığı interaktif WebGL sahnesi; sağ sütunda ise seri bağlantı durumu, anlık telemetri kartları (X, Y, Roll, Pitch, Hız), canlı Chart.js grafik panelleri ve mikrodenetleyiciden gelen ham UART loglarının aktığı seri monitör konsolu yer alır.

2. style.css (Görsel Tasarım ve Kullanılabilirlik)

Endüstriyel otomasyon yazılımlarına uygun olarak göz yormayan derin koyu arka plan (#090d16) ve cam hissi veren yarı saydam kart tasarımı (backdrop-filter: blur(12px)) kullanılmıştır. Modern Plus Jakarta Sans ve terminal için JetBrains Mono yazı tipleriyle yüksek okunabilirlik sağlanmıştır.

3. simulation.js (3D Kinematik ve Fizik Çekirdeği)

Sistemin en kapsamlı modülüdür. İçerisinde Three.js sahne kurulumu, kamera kontrolü, yönlü ışıklandırma, gölge haritaları ve PBR metalik malzeme tanımları yer alır. updateKinematics(roll, pitch, yaw, height) metodu, üst plaka oryantasyonuna karşılık gelen 6 adet bağımsız bacağın kapalı çevrim vektörlerini hesaplar; servo kollarını açılandırarak karbon çubukları mafsallar arasında uzatır. "Simülatör Modu" aktif edildiğinde ise içsel fizik motoru devreye girerek topun hareketini ve kontrol çevrimini işletir.

4. charts.js (Gerçek Zamanlı Grafik Yöneticisi)

Canvas tabanlı Chart.js kütüphanesini yönetir. Grafiklerin performansını korumak için responsive: true, animation: false ve elements.point.radius: 0 modlarında çalışır. Sürekli gelen 20-30 Hz'lik veri akışında dizi boyutunu 150 örnekte sınırlayarak bellek taşmalarını önler.

5. app.js (İletişim ve Entegrasyon Katmanı)

Web Serial API üzerinden donanımla el sıkışır. Rezistif panelden okunan ham dokunmatik değerleri kinematik eksenlere dönüştürür. Donanım bağlantısı kesildiğinde veya yeniden bağlandığında arayüz butonlarını ve bildirim rozetlerini günceller.

6. serve.ps1 (Sıfır Bağımlılıklı Yerel Sunucu)

Geliştirilen web uygulaması Web Serial API ve modern ES6 JavaScript modülleri kullandığı için doğrudan file:// protokolü üzerinden çalıştırılamaz (tarayıcı güvenlik politikaları gereği http://localhost üzerinden sunulmalıdır). Sistemde Python veya Node.js kurulu olmama ihtimaline karşı Windows'un yerleşik .NET altyapısını (System.Net.HttpListener) kullanan saf bir PowerShell HTTP sunucusu kodlanmıştır. Bu sayede proje herhangi bir ek yükleme yapılmaksızın tek tıkla çalışabilmektedir.

6.4. Bölüm Sonucu ve Değerlendirme

Geliştirilen Web Tabanlı Dijital İkiz ve Telemetri Mimarisi, 6-DOF Stewart platformu projesinin sadece fiziksel bir prototip olmaktan çıkıp endüstri standardında izlenebilir, test edilebilir ve uzaktan yönetilebilir bir siber-fiziksel sisteme dönüşmesini sağlamıştır.

Bu altyapı sayesinde kontrolcü parametreleri donanıma fiziksel zarar verme riski olmadan sanal ikiz üzerinde güvenle doğrulanmış, kısa kenardaki rezonans problemi grafiksel telemetri üzerinden anlık olarak teşhis edilmiş ve donanım testlerinde yüksek hassasiyetle kararlılık elde edilmiştir.
